3. Description of Web Development Terms

HTML
HTML is used to create the structure of a webpage.
CSS
CSS is used to style and design webpages.
JavaScript
JavaScript is used to add interactivity and dynamic behavior to webpages.
Frontend
Frontend is the part of a website that users can see and interact with.
Backend
Backend handles server-side logic, databases, and application processing.
